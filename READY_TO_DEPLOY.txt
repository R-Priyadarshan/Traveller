================================================================================
                      TROUBLESHOOTING
================================================================================

If deployment fails:
  1. Check Railway logs for error message
  2. Verify environment variables are set
  3. Check .env is NOT committed to git
  4. Restart deployment

If API returns 500 error:
  1. Check logs in Railway dashboard
  2. Verify GEMINI_API_KEY is set
  3. Verify TAVILY_API_KEY is set
  4. Check API key validity at source

If it's slow:
  1. First request after deploy takes 10s (cold start)
  2. Subsequent requests are fast (<5s)
  3. Normal on free tier
  4. Upgrade to paid tier if needed

If container keeps restarting:
  1. Check logs for error
  2. Verify Port 8000 is correct
  3. Check memory isn't exhausted
  4. Increase memory allocation
